As senhas guardadas no cofre são cifradas com uma chave própria, VAULT_ENCRYPTION_KEY — diferente da chave usada para as credenciais de integração (Auvo/Telegram). Ela fica só na variável de ambiente do servidor, nunca no banco de dados e nunca no repositório.

Se essa chave se perder, todas as senhas do cofre ficam irrecuperáveis — não existe "esqueci a senha" aqui, é cifragem de verdade. Guarde uma cópia da chave em um lugar seguro, separado do backup do banco de dados. Se as duas coisas forem perdidas ou vazarem juntas, a proteção da cifragem não serve de nada.

Para gerar uma chave nova (ex.: na primeira instalação): 

python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

Coloque o valor gerado na variável VAULT_ENCRYPTION_KEY do ambiente (arquivo .env ou variável do sistema) e reinicie o Power Central. Trocar a chave depois torna as senhas já salvas ilegíveis — só cifre com ela senhas novas se planeja mantê-la para sempre.
